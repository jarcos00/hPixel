# Halliday Gradient Generator

A dynamic web-based generative art application for creating pixel-based gradient animations with advanced customization and export capabilities.

## Features

- Real-time gradient animation generation
- Multiple effect modes (Wavy, Orbit, Hectic)
- Customizable pixel size and spacing
- Color customization
- Video recording with MP4 export
- SVG and PNG export options
- Responsive design

## Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

## Deployment

This project is configured to deploy automatically to GitHub Pages when pushing to the main branch. To deploy manually:

1. Fork this repository
2. Enable GitHub Pages in your repository settings:
   - Go to repository Settings > Pages
   - Under "Build and deployment", select "GitHub Actions" as the source
3. Push to the main branch

The site will be available at `https://[your-username].github.io/[repository-name]/`
